# AM-CR10 2D 코드 리더 (가상 제품 설명서, 검색용 요약)

사람용 원본: docs/manual/devices/cr10-code-reader.html. 가상 장비용 가상 제품이며 실제 제조사 설명서와 관계없다.

## AM-CR10 개요, 사양, 진단

INFEED에서 스토퍼(STOPPER 0.15 s)가 하우징을 세운 뒤 2D 코드를 읽는 고정식 리더. ID_READ 0.3 s, 읽기 한 번 실패율 약 0.3 %, 실패하면 "2D code read fail attempt=1" 경고 후 한 번 더 읽는다. 두 번 모두 실패(제품 약 10만 개에 1개)하면 E1001 2D code read fail, 리셋하면 그 제품을 불량(SCRAP_E1001)으로 뺀다. 성공하면 "Part received serial=…". 제품 번호 형식 L{연월일 6자리}-{로트 순번 3자리}-{로트 안 순번 4자리}, 로트 500개, 모델 변경 때 새 로트. 재시도 경고가 드물면 정상, 갑자기 잦아지면 리더 창 오염이나 코드 인쇄 불량 로트. 코드 리더는 토출 품질과 관계없어 비드 불량·토출량 원인에서 제외한다.
