# DSP-CELL-01 접착제 디스펜싱 셀 (가상 장비 설명서, 검색용 요약)

사람용 원본: docs/manual/devices/dsp-cell-01.html. 가상 장비의 가상 설명서이며 실제 제조사 설명서와 관계없다.

## DSP-CELL-01 개요와 공정 흐름

앞 설비에서 들어온 리어 하우징에 접착제 비드를 그리고 검사해 합격품은 뒤 설비로, 불량품은 NG 버퍼(24개)로 보내는 셀. 다섯 스테이션 직렬: INFEED(앞 설비에서 받기, 2D 코드 읽기) → VISION(기준 핀 정렬, 남은 위치 차 측정) → DISPENSER(진공 고정, 높이 확인, 비드 도포, 정기 중량 검사) → INSPECTION(비드 폭·위치·결함) → OUTFEED(합격품 넘기기, 불량품 NG 버퍼). 스테이션은 동시에 서로 다른 제품을 처리하고, 가장 오래 걸리는 DISPENSER(레시피 A 이송 포함 약 6.4 s)가 사이클을 정한다. 중량 검사가 있는 제품은 약 8 s 더 걸린다. 품질 문제의 원인은 대부분 DISPENSER의 부품(컨트롤러, 히터, 니들, 시린지, 진공 지그, 저울, 높이 레이저)과 공장 공기에 있다.

## 레시피와 설정 변경 기록

REAR_HOUSING_ADH_A: 토출 250 kPa, 2.0 s, 대기 0.3 s, 35.0 °C, 갭 0.15 mm, 12.0 mg ±10 %, 폭 0.80(0.68–0.92) mm. REAR_HOUSING_ADH_B: 220 kPa, 1.6 s, 0.3 s, 35.0 °C, 0.12 mm, 8.5 mg ±10 %, 0.65(0.55–0.75) mm. 공정은 처음 검증한 값을 기준으로 맞춰져 있어 값을 바꾸면 토출량과 폭이 실제로 바뀐다. 운전 중 설정값만 바꾸면 "Recipe parameter changed param=… old=… new=…"가 남고 정비 담당 조치나 모델 변경 때 저장된 레시피 값으로 돌아간다. 저장된 레시피를 고치면 "Recipe edited param=… old=… new=…"가 남고 계속 유지된다.

## 운전, 교대, 안전

자동 운전 전 원점 복귀 필요(전원 투입, 비상 정지, 수동 조작 뒤). START는 AUTO 모드, 원점 복귀 완료, 알람 없음, 안전 조건 충족일 때만. 사이클 정지는 새 제품을 받지 않고 라인이 비면 멈추며 휴식과 모델 변경에 쓴다. 주간 조 08:00(OP-A, OP-B), 야간 조 20:00(OP-C, OP-D). 휴식 10:00–10:10, 12:00–13:00, 15:00–15:10, 22:00–22:10, 00:00–01:00, 03:00–03:10. 휴식 중에도 시린지 장착 시간은 흐르고 히터는 온도를 유지한다. 비상 정지 E9100(서보 전원 차단, 원점 복귀 필요), 앞면 안전 도어 2개 운전 중 열림 E9101, 메인 공기 300 kPa 미만 E9001.

## 알람 목록과 리셋 동작

다시 시도(그 스테이션 순서를 처음부터): E3001 진공 미달, E3002 시린지 온도, E3003 잔량, E3005 중량 검사, E3006 가사 시간, E5001 NG 버퍼 가득, E9001 메인 공기. 제품 제거(불량으로 빼고 다음): E1001 코드 읽기 실패, E2001 정렬 마크 없음, E2002 정렬 위치 초과. 계속(이미 판정한 제품을 내보냄): E4001 연속 비드 불량. E9100은 원점 복귀 뒤 시작, E9101은 도어를 닫은 뒤.

## 작업자 표준 조치

같은 문제가 90분 안에 다시 오면 다음 단계로 넘어간다. E3001: 진공 점검 → 진공 점검 → 진공 패드 교체. E3002: 정비 담당. E3003·E3006: 시린지 교체. E3005: 니들 청소 → 시린지 교체 → 정비 담당. E4001 기본: 니들 청소 → 니들 청소 → 정비 담당, BEAD_VOID: 퍼지 → 시린지 교체 → 정비 담당, STRINGING: 니들 청소 → 정비 담당, BEAD_OFFSET·WIDTH_HIGH: 니들 위치 교정 → 정비 담당. E9001: 공기 점검 → 공기 점검 → 정비 담당. 조치는 "Maintenance start action=…"으로 남는다. 니들 청소 5–10분, 위치 교정 5–10분, 시린지 교체 8–15분, 퍼지 2–4분, 패드 교체 10–20분, 정비 담당(ENG-01) 30–60분으로 열전대 교정·니들 청소·위치 교정·설정값 복원을 한다. 진공·공기·비전 점검은 눈으로 확인만 하고 부품을 바꾸지 않는다. 공장 공기 저하는 장비 안의 조치로 고쳐지지 않고 공기가 돌아오면 사라진다.

## 기록 파일

런마다 폴더 하나, 시각 형식 YYYY-MM-DD HH:MM:SS.mmm. event.log: 단계 완료, 경고, 조작, 정비, 레시피 변경 등 모든 사건("시각 등급 스테이션 메시지 키=값"). alarm.log: 알람 SET·CLEAR와 상세. sensor_trend.csv(1초): 모드, 흡착 진공, 토출 압력, 밸브 열림, 시린지 온도, 잔량. production.csv(제품마다): 번호, 로트, 레시피, 사이클 시간, 정렬값, 진공, 압력, 온도, 높이, 비드 폭·위치, 판정. io_trace.csv: 입출력 신호 변화. machine_info.json: 장비 번호, 시작·끝 시각, 레시피, 예정 휴식, 입출력 지도. 공장 공기 압력과 니들 개방률, 실제 온도 같은 내부 상태는 기록에 직접 남지 않으므로 관련 신호로 간접 판단한다.
