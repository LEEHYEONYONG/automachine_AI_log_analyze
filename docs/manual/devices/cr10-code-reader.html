1개요

AM-CR10은 투입부에서 하우징의 2D 코드를 읽어 제품을 식별합니다. 스토퍼가 하우징을 세운 뒤 한 번 읽고, 실패하면 한 번 더 읽습니다. 읽은 제품부터 장비 기록(생산 로그, 이벤트 로그)에 제품 번호가 붙습니다.

2사양

항목값비고
읽기 시간ID_READ 0.3 sSTOPPER(0.15 s) 다음
읽기 실패율읽기 한 번에 약 0.3 %실패하면 "2D code read fail attempt=1" 경고 후 재시도
두 번 모두 실패제품 약 10만 개에 1개E1001

3제품 번호

L{연월일 6자리}-{로트 순번 3자리}-{로트 안 순번 4자리} 예) L261104-002-0137 : 2026-11-04 두 번째 로트의 137번째 제품 로트 크기 500개, 모델 변경 때 새 로트

읽기에 성공하면 이벤트 로그에 "Part received serial=…"이 남습니다.

4관련 알람과 진단

코드장비 메시지리셋하면
E10012D code read fail그 제품을 불량(SCRAP_E1001)으로 빼고 다음 제품
증상가능한 원인조치
재시도 경고가 드물게정상 범위조치 불필요
재시도 경고가 갑자기 잦아짐리더 창 오염, 코드 인쇄 불량 로트리더 창 청소, 앞 공정에 코드 품질 확인 요청

코드 리더는 토출 품질과 관계가 없습니다. 비드 불량이나 토출량 문제를 볼 때는 고려하지 않아도 됩니다.
