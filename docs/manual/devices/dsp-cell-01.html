1개요

DSP-CELL-01은 앞 설비에서 들어온 리어 하우징에 접착제 비드를 한 줄 그리고, 비드를 검사해 합격품은 뒤 설비로, 불량품은 NG 버퍼로 보내는 자동 셀입니다. 제품은 투입 → 정렬 → 도포 → 검사 → 배출의 다섯 스테이션을 차례로 지납니다. 품질을 정하는 핵심은 도포 스테이션(DISPENSER)이며, 이 스테이션이 사이클 시간도 정합니다.

주의

공정은 처음 검증한 레시피 값을 기준으로 맞춰져 있으므로, 값을 바꾸면 토출량과 비드 폭이 실제로 바뀝니다. 바꾸는 방법은 두 가지이고 기록이 다릅니다. 지금 운전 중인 설정값만 바꾸면 "Recipe parameter changed param=… old=… new=…"가 남고, 정비 담당 조치나 모델 변경 때 저장된 레시피 값으로 돌아갑니다. 저장된 레시피 자체를 고치면 "Recipe edited param=… old=… new=…"가 남고, 다시 고칠 때까지 그대로 유지됩니다.

주의

공장 공기 저하는 장비 안의 조치로 고쳐지지 않습니다. 공기가 돌아오면 저절로 사라집니다. 진공 점검만으로는 패드 마모가 고쳐지지 않으므로, 같은 알람이 반복되면 점검을 반복하지 말고 패드를 바꿉니다.
